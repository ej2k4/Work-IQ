# Temperature Converter Documentation

## c_to_f Function
- **Parameters**: Takes a float `celsius` as input.
- **Return Type**: Returns a float representing the temperature in Fahrenheit.
- **Usage Example**:
  ```python
  result = c_to_f(30)
  print(result)  # Output: 86.0
  ```

## f_to_c Function
- **Parameters**: Takes a float `fahrenheit` as input.
- **Return Type**: Returns a float representing the temperature in Celsius.
- **Usage Example**:
  ```python
  result = f_to_c(98.6)
  print(result)  # Output: 37.0
  ```
